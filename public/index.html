Defensive Threat Matrix & Scoring System

SentinelScan replaces guesswork and black-box AI with deterministic, evidence-based threat assessment. Every point assigned to a file is backed by physical binary or structural indicators.

Known Malware Signature +85 Pts

ClamAV signature match confirming known virus, trojan, ransomware, or cryptominer pattern.

Decompression Bomb +80 Pts

Archive with abnormal compression ratio (>100:1) or total expansion size exceeding 1 GB designed for resource starvation.

Zip Slip / Traversal +75 Pts

Archive entries containing ../ sequences or absolute filesystem paths designed to escape destination extraction directories.

Disguised Executable +65 Pts

Severe extension spoofing: executable binary header (MZ/PE or ELF) disguised with image or document extension (.pdf, .jpg, .png).

Remote Template Injection +65 Pts

Office document configured with external relationship targets fetching remote weaponized templates via HTTP upon opening.

PDF /Launch Action +60 Pts

PDF document configured with automatic application launch directives triggering system process execution.

W^X Memory Invariant Violation +45 Pts

PE or ELF section marked both Writable and Executable (IMAGE_SCN_MEM_WRITE | IMAGE_SCN_MEM_EXECUTE), indicating self-modifying code or stagers.

High Section Entropy (> 7.2) +30 Pts

Shannon entropy calculation indicating encrypted payloads, packed stubs (UPX), or hidden binary data.

Zero-Execution Architecture & Defense In Depth

Traditional malware sandboxes execute binaries inside virtual machines, risking hypervisor breakouts, anti-evasion sleeps, or accidental network beaconing. SentinelScan utilizes a Zero-Execution Static Dissection architecture.

Read-Only Binary Inspection

Files are parsed strictly as passive byte streams. Headers, sections, symbols, and streams are dissected using pure mathematical calculations (Shannon entropy, struct unpacking) without launching child processes.

Cryptographic Token Ownership

Each upload session is authenticated with a 128-bit cryptographic client token. Only the entity that submitted the file has authorization to trigger manual erasure or inspect non-public telemetry.

Automated 5-Minute File Shredding

To prevent data hoarding and liability, all uploaded file payloads are automatically and permanently deleted from disk 5 minutes after analysis completion. Verification checks ensure zero residual traces.

Client Authentication & Privacy Preferences

Your client token verifies your ownership of uploaded scans and allows immediate payload deletion.

About SentinelScan

SentinelScan is a real, open-source file safety and malware analysis platform built for defensive security engineers, malware researchers, and organizations needing safe, zero-cost, on-premise threat inspection.

Core Design Principles

  • Authentic Findings: Zero simulated outcomes or fake status indicators.
  • Zero-Execution Guarantee: Files are dissected passively; never executed.
  • 1 GB Streamed Capacity: Chunked pipeline prevents memory exhaustion.
  • Pluggable Storage: Works out of the box on local disk or with S3/B2 cloud storage.
  • Free-First Architecture: Complete open-source stack using native Node.js 24 and SQLite.
